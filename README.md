# archish27.github.io

Personal site of Archish Thakkar. Vite + React, Lenis for scroll, Framer Motion for motion, prerendered to static HTML.

```bash
npm install
npm run dev      # local dev server
npm run build    # dist/ with prerendered index.html
npm run preview  # serve dist/
```

Pushes to `develop` build and publish `dist/` to the `main` branch, which GitHub Pages serves.
